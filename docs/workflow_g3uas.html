The claim under test

the same series, a different drag

The parallel is exact, and it is the reason this port is worth doing. Prandtl's lifting line writes the spanwise circulation as a Fourier series and gets an induced-drag penalty δ = Σ n (An/A1)², minimised when only the first mode survives — the elliptic loading. Slender-body wave drag writes D/q = (π/4) Σ n An², minimised when only the first mode survives — the von Kármán ogive. Same structure, same optimum, different physical drag. The series code in sizing/wavedrag.py transfers with the integrand swapped.

Where this gets harder than the rocket

known before starting
PHYSICS RISKlow Reynolds

Transition is not a detail

Chord Reynolds number around 8 × 10⁵

A Group 3 wing sits in the range where laminar separation bubbles form and where a fully-turbulent RANS solve can be wrong about drag by tens of percent. The rocket never had this problem: at Mach 2 and Re 10⁷ the boundary layer is turbulent everywhere and the question does not arise.

Consequence. Either a transition model is used and its uncertainty declared, or the solve is run fully turbulent and reported as an upper bound on friction drag. Quietly running turbulent and calling it validation would be the failure mode.

LOOP RISKclosure

The fuel fraction bites back

Endurance and fuel mass are mutually defined

The rocket's propellant was a design variable the sizer moved directly. Here fuel is an outcome: more fuel raises weight, which raises induced drag, which burns more fuel. The fixed point can diverge for a demanding endurance target rather than simply reporting an infeasible design.

Consequence. The loop needs an explicit non-convergence path that reports the divergence as a result — the requirement being unreachable is itself the finding, exactly as the rocket's impossible Mach-1.5 impact was.

Anatomy of a design point

from design vector to CFD verdict
  1. A design vector is proposed — span, aspect ratio, the spanwise load blend, installed power and fuel volume.
  2. The nTop notebook lofts the wing from the splined chord and twist, and closes the fuselage, boom and tail around it.
  3. nTop returns measured wetted area per component, tank volume, CG, inertia and the spanwise chord.
  4. masses builds the group-weight statement; empty mass is the correlation-driven line that endurance is most sensitive to.
  5. aero solves the lifting line for the splined loading, adds a parasite build-up on the measured wetted areas.
  6. powerplant matches engine BSFC and propeller efficiency at the loiter condition — the operating point, not a datasheet peak.
  7. mission integrates climb, cruise out, loiter, cruise back and reserve; the loop repeats until fuel mass stops moving.
  8. The converged airframe escalates to RANS, which returns span efficiency and separation behaviour the lifting line cannot see.
